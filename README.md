# Carry On — Pick Up Blocks & Mobs Mod

[![Download Latest](https://img.shields.io/github/v/release/Typhoonoilevel/carry-on-pickup-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Typhoonoilevel/carry-on-pickup-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Pick up tile entities, chests, and mobs by sneaking and right-clicking to carry them anywhere.

![Carry On — Pick Up Blocks & Mobs Mod Preview](https://cdn.modrinth.com/data/FmZ1BXbK/images/6d83ba312a478e2a26d71b2b6cd9c5697596d94c_350.webp)

## Features

- Carry any chest or barrel without breaking it
- Pick up passive and neutral mobs by hand
- Move machines from other mods without losing contents
- Stack multiple carried entities with config options
- Blacklist specific blocks or mobs via config

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
